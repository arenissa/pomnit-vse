# Помнить всё! — Telegram-бот для напоминаний

Telegram-бот-напоминалка на **aiogram 3** + **SQLite**: принимает заметку со сроком, присылает напоминание за 30 минут (настраивается), даёт кнопки «Выполнено / Отложить» и красивый постраничный просмотр заметок.

[Открыть бота в Telegram](https://t.me/napomni_app)

## Зачем этот проект

Записать задачу проще, чем удерживать её в голове. «Помнить всё!» принимает сообщения вроде «Оплатить интернет завтра в 10:00», сохраняет заметку и напоминает о ней в Telegram. Срок можно перенести кнопкой, а выполненное — убрать из активных задач.

Проект разработан с помощью ИИ и развёрнут на VPS Beget в Docker с Python 3.12. В репозитории — исходный код и 46 автоматических тестов. Токены и база с личными заметками не публикуются.

**Стек:** Python 3.12 · aiogram 3 · SQLite · Docker.

## Возможности

- **Добавление одной строкой**: `Оплатить интернет завтра в 10:00` — бот сам выделит задачу и срок.
- **Свободный ввод времени на русском**: `18:30`, `9 утра`, `вечером`, `завтра`, `в пятницу`, `5 ноября`, `30.10.2026`, `через 2 часа`, `через полчаса`, `через 3 дня`.
- **Напоминание заранее** (по умолчанию за 30 минут) с кнопками:
  - ✅ **Выполнено** — заметка уходит в выполненные (с возможностью вернуть);
  - ⏰ **Отложить** — 15 мин, 30 мин, час, 3 часа, «сегодня вечером», «завтра 9:00», «завтра 18:00», «через неделю» или **свой срок** текстом.
- **Повторные напоминания**, если не отреагировал (в `.env.example` — 3 раза каждые 10 минут; без настройки интервала повторы выключены).
- **Уведомление о наступившем сроке**.
- **Просмотр заметок карточками**: листание ◀️ ▶️, фильтры «Активные / Сегодня / Просроченные / Выполненные», из карточки можно выполнить, отложить, изменить текст/срок или удалить.
- **Настройки**: интервал напоминания и часовой пояс (список + свой IANA).
- Каждый пользователь видит только свои заметки; опционально — белый список ID.

## Установка

Требуется **Python 3.11 или новее** (проверено на Python 3.12).

```bash
git clone https://github.com/arenissa/pomnit-vse.git
cd pomnit-vse
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

cp .env.example .env
# впишите BOT_TOKEN от @BotFather
```

## Запуск

```bash
python run.py
```

Бот работает через long polling, отдельный вебхук/сервер не нужен. База создаётся автоматически в `data/reminders.db`.

## Запуск в Docker на сервере

Нужен Docker с плагином Compose. Создайте `.env` по образцу `.env.example` и впишите свой токен от @BotFather:

```bash
cp .env.example .env
# Отредактируйте .env, затем:
chmod 600 .env
mkdir -p data
docker compose up -d --build
docker compose logs --tail 30
```

База хранится в папке `data` на сервере и сохраняется при пересоздании контейнера. Политика `unless-stopped` включает автоматический перезапуск, пока контейнер не остановлен вручную. Для работы после перезагрузки сервера должна автоматически запускаться служба Docker.

После замены токена в `.env` пересоздайте контейнер:

```bash
docker compose up -d --force-recreate
```

Запускайте только один экземпляр с одним токеном. Не публикуйте `.env` и содержимое `data`. Для резервного копирования используйте SQLite Backup API или остановите бота перед копированием базы.

## Настройки (.env)

| Переменная | По умолчанию | Описание |
|---|---|---|
| `BOT_TOKEN` | — | токен бота, обязателен |
| `TIMEZONE` | `Europe/Moscow` | пояс для новых пользователей |
| `REMIND_BEFORE_MINUTES` | `30` | за сколько минут напоминать |
| `POLL_INTERVAL_SECONDS` | `5` | как часто планировщик проверяет базу |
| `REPEAT_AFTER_MINUTES` | `0` (в примере `10`) | интервал повторных напоминаний, `0` — выключить |
| `MAX_REPEATS` | `3` | максимум повторов |
| `DEFAULT_TIME` | `12:00` | время, если указана дата без времени |
| `DATABASE_PATH` | `data/reminders.db` | путь к SQLite-файлу |
| `ALLOWED_USER_IDS` | пусто | белый список ID через запятую |

## Как это работает

1. При создании заметки вычисляется `remind_at = срок − интервал напоминания` (если момент уже прошёл — напоминание отправляется сразу).
2. Планировщик раз в `POLL_INTERVAL_SECONDS` секунд выбирает готовые к отправке записи и **атомарно** захватывает их (`active → notified`), поэтому одно и то же напоминание не уйдёт дважды.
3. Если пользователь не отреагировал, планируется повтор; после `MAX_REPEATS` повторов напоминания прекращаются.
4. «Выполнено» переводит заметку в `done`, «Отложить» сбрасывает состояние напоминаний и пересчитывает `remind_at` от нового срока.

## Ограничения

- Long polling рассчитан на один запущенный экземпляр. Для нескольких инстансов нужен вебхук и внешняя очередь.
- SQLite подходит для личного бота; для большой нагрузки стоит перейти на PostgreSQL.
- Внутри одного дня бот хранит время в UTC, а показывает в часовом поясе пользователя.
